Silvanus

Meeting notes you can trust, written on your Mac.

Silvanus records both sides of a call and writes a faithful transcript, your notes, and the to-dos. Everything stays on your Mac as plain files. No account, no server, and no bot joining your call.

Install

Paste this into Terminal and press Return:

curl -fsSL https://get-silvanus.space.fast/install.sh | sh

It downloads the latest build, checks it, puts Silvanus in your Applications folder, and opens it. After that, Silvanus updates itself; it checks once a day and asks first. Needs a Mac with Apple silicon and macOS 26 or newer.

Silvanus isn't notarized by Apple yet, so the Terminal install is the smooth path; a browser download would be blocked by macOS.

Then a few things only you can do

  1. Allow the microphone and system audio. Start a recording (⇧⌘R), and macOS asks for both. Silvanus asks the first time you record, never at launch.
  2. Let the speech model download. The first transcript fetches Parakeet (about 450 MB) on its own.
  3. If you like, add the extras. Connect a calendar in Settings so recordings take the event's title, and download a Gemma 4 model from Home for to-dos and summaries.

Installing with an AI agent

The installer never asks a question, so an agent can run it for you. Point it at the install guide, or have it run:

curl -fsSL https://get-silvanus.space.fast/install.sh | sh -s -- --json

It prints one JSON line with the result and the steps to hand back to you. llms.txt has the short version for agents.

What it's built on

Silvanus transcribes with FluidAudio and NVIDIA's Parakeet, writes summaries with Google's Gemma 4 through llama.cpp, and updates itself with Sparkle. It's released under the MIT License.
